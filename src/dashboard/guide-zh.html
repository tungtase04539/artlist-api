🎬 Artlist 视频生成 API · 使用指南

基于 Seedance 2.0 等模型的 AI 视频生成接口 · 仅需 API（无需界面）· Base URL：https://artlist-api.vercel.app

1. 概述

  • 纯 REST API，返回 JSON。支持文生视频、图生视频、多图生视频（最多 9 张）。
  • 异步流程：POST /v1/videos 提交任务 → 轮询 GET /v1/videos/{id} 直到 status=done 拿到视频链接。
  • 按积分（credits）计费，价格由模型 + 参数决定。你的额度和限流由管理方分配。

2. 认证

所有 /v1/* 接口都需在请求头带上你的密钥：

x-api-key: <你的 API_KEY>

密钥形如 alk_xxxxxxxx...，请妥善保管、勿泄露。缺失或错误返回 401。

3. 快速开始

KEY="<你的 API_KEY>"
BASE="https://artlist-api.vercel.app"

# ① 提交生成任务
curl -X POST "$BASE/v1/videos" -H "x-api-key: $KEY" \
  -H 'content-type: application/json' \
  -d '{"modelGroupId":358,"prompt":"a red panda skateboarding, cinematic","maxCredits":2000}'
# → {"jobId":"...", "status":"processing", "credits":1200}

# ② 用返回的 jobId 轮询（建议每 3~5 秒一次）
curl "$BASE/v1/videos/<jobId>" -H "x-api-key: $KEY"
# → status=processing … 最终 → {"status":"done","videoUrl":"https://...mp4?Expires=...&Signature=...","credits":1200}

4. 接口列表

方法路径说明
GET/v1/me账户信息 + 剩余积分 + 限流
GET/v1/models可用视频模型列表（含 modelGroupId、features）
GET/v1/models/{id}某模型的完整参数（可选项、默认值）
POST/v1/videos创建视频（异步），返回 jobId
GET/v1/videos/{id}查询任务状态，done 时含 videoUrl
GET/v1/videos你的历史任务列表

机器可读文档（OpenAPI）：/openapi.json · 在线调试：/docs

5. 创建视频 · POST /v1/videos

请求体为 JSON。必须提供 prompt（或放在 settings.prompt 里）。

字段类型说明
modelGroupIdint模型 ID（见 /v1/models）。默认 358=Seedance 2.0，416=Seedance 2.0 Mini。
promptstring视频描述文字。可在文中插入图片标签 @img1 @img2 …。
settingsobject与 /v1/models/{id} 对应，如 resolution、duration、aspect_ratio、generate_audio。
imageuri单张图片（图生视频）。公网 http/https 链接。
images[]uri[]最多 9 张图片（多图生视频）。
videos[] / audios[]uri[]输入视频 / 音频。
endFrameuri结尾帧图片。
resolution / duration / aspectRatio / generateAudio—settings.* 的简写形式。
maxCreditsint价格上限：报价超过则拒绝，防止意外超支。建议每次都带上。
expectedCreditsint你预期的价格：与真实报价不符则拒绝（防错/防篡改）。
chatSessionIdstring可选，留空则系统自动创建/复用会话。

媒体输入必须是公网可访问的 http/https 链接（不接受内网/IP 私网地址）；服务器会自动下载并上传。图片 png/jpg/webp，视频 mp4/mov/webm，音频 mp3/wav/m4a/aac。

示例：图生视频

curl -X POST "$BASE/v1/videos" -H "x-api-key: $KEY" -H 'content-type: application/json' -d '{
  "modelGroupId": 358,
  "prompt": "gentle zoom in, cinematic lighting",
  "image": "https://example.com/photo.jpg",
  "maxCredits": 2000
}'

示例：多图生视频（最多 9 张）

curl -X POST "$BASE/v1/videos" -H "x-api-key: $KEY" -H 'content-type: application/json' -d '{
  "modelGroupId": 358,
  "prompt": "smooth morphing sequence with ambient soundtrack",
  "images": ["https://example.com/1.jpg", "https://example.com/2.jpg", "https://example.com/3.jpg"],
  "settings": { "resolution": "720p", "duration": 4, "aspect_ratio": "16:9", "generate_audio": true },
  "maxCredits": 2000
}'

6. 查询状态 & 视频链接

curl "$BASE/v1/videos/<jobId>" -H "x-api-key: $KEY"
status含义
processing生成中，继续轮询
done完成，字段 videoUrl 为可直接下载/播放的链接
failed失败，已自动退还积分，见 error
⚠️ videoUrl 是已签名的 CloudFront 链接（带 Expires、Key-Pair-Id、Signature），任何地方都能打开、有效期约 10 年。请完整保存整个链接（含 ? 后所有参数）；若截断丢失 Key-Pair-Id，会报 MissingKey 无法访问。

7. 积分与计费

  • 价格由模型 + 参数决定（如 1080p 比 720p 贵、时长越长越贵），由服务端实时报价。
  • 提交任务时按报价扣除积分；若生成失败会自动退还。
  • 随时查询余额：GET /v1/me。积分不足返回 402。

8. 错误码

HTTPcode说明
400—参数错误（缺 prompt、参数非法）
400MEDIA_ERROR媒体链接无法下载/格式不支持/非公网地址
400PRICE_MISMATCHexpectedCredits 与真实价不符
401—缺失或无效的 x-api-key
402INSUFFICIENT_CREDITS积分不足
403—账号被暂停
429RATE_LIMITED超过限流（每分钟/每天/并发）
503SESSION_EXPIRED上游临时不可用，请稍后重试

9. 限流

每个密钥有每分钟 / 每天请求上限，以及并发任务上限（超出返回 429）。请勿多方共用同一密钥——系统会检测异常使用。当前额度可在 GET /v1/me 查看。

10. 代码示例

JavaScript (fetch)

const BASE = "https://artlist-api.vercel.app", KEY = "<你的 API_KEY>";
const h = { "x-api-key": KEY, "content-type": "application/json" };

const { jobId } = await (await fetch(`${BASE}/v1/videos`, {
  method: "POST", headers: h,
  body: JSON.stringify({ modelGroupId: 358, prompt: "a red panda skateboarding", maxCredits: 2000 }),
})).json();

let job;
do {
  await new Promise(r => setTimeout(r, 4000));
  job = await (await fetch(`${BASE}/v1/videos/${jobId}`, { headers: h })).json();
} while (job.status === "processing");
console.log(job.videoUrl);

Python (requests)

import time, requests
BASE, KEY = "https://artlist-api.vercel.app", "<你的 API_KEY>"
h = {"x-api-key": KEY}

job = requests.post(f"{BASE}/v1/videos", headers=h, json={
    "modelGroupId": 358, "prompt": "a red panda skateboarding", "maxCredits": 2000
}).json()

jid = job["jobId"]
while True:
    time.sleep(4)
    job = requests.get(f"{BASE}/v1/videos/{jid}", headers=h).json()
    if job["status"] != "processing":
        break
print(job.get("videoUrl") or job.get("error"))

如需调整额度、限流或更换密钥，请联系服务提供方。
